# Deploy & Pray (D&P) — CET257 Assignment 2 / B2
## Promotional Website Submission

This folder contains the B2 promotional website and the supporting documents required by the assessment brief.

### Run in VS Code
**Option 1 — simplest:** open `index.html` in a browser.

**Option 2 — recommended:** open this folder in VS Code and use a local static server such as the VS Code Live Server extension, then open `index.html`.

There is no npm install, build command or database.

### Important before final Canvas submission
The assessment brief asks for a website URL as well as an electronic copy of the website files. This package is ready for local demonstration in VS Code. Before submission, publish the same folder using your chosen free static hosting service (for example GitHub Pages) and paste the resulting URL into the Canvas submission.

Also replace/add the team's real LinkedIn/GitHub/contact details if those accounts have been created. No invented external account links have been added.

The site follows the D&P Assignment 1 marketing direction: Home, About, Our Work, Team and Contact; AutoTrain 3D is the lead case study; and the supplied rose/blush/champagne/ivory/dark-ink identity is used throughout.
