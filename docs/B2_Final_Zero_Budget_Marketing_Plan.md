# D&P — Finalised Zero-Budget Marketing Plan
## CET257 Enterprise Project — Assignment 2 / B2

### 1. Purpose
Deploy & Pray (D&P) will use a zero-budget approach to build visibility and credibility, turn AutoTrain 3D into a referenceable portfolio case study, and strengthen the relationship with the client.

### 2. Target audiences
| Audience | What they need to see |
|---|---|
| Client | Professionalism, responsiveness and a working prototype |
| Module leader / moderators | A considered, deliverable-ready marketing plan |
| Future employers / recruiters | A polished, coherent team portfolio |
| University careers service & peers | Visibility of the project and team |

### 3. Channels and tactics
| Channel | £0 tactic | Owner | Target |
|---|---|---|---|
| LinkedIn | Create a D&P company page and publish weekly progress posts using #CET257 and university tagging | Sweta | 50 followers by Week 8 |
| GitHub | Public organisation profile with a polished README and pinned AutoTrain 3D repository | Krishala | README with 3 screenshots and deployment link |
| University channels | Submit AutoTrain 3D to a school showcase / demo day | Rustam | At least 1 showcase or demo |
| Canva Free | Create a one-page company profile as a client presentation leave-behind | Sambriddhi | Complete before client presentation |
| Student / developer communities | Share progress in relevant student/dev communities, including university Discord/Teams channels | All | Post in 3 relevant communities by Week 8 |
| Client testimonial | Request a short written testimonial after client sign-off | Sweta | Obtain 1 testimonial after sign-off |

### 4. Timeline
**Now → presentation:** Finalise brand assets, launch LinkedIn page and GitHub organisation, and publish website v1.

**Post-presentation:** Publish the demo video and request a client testimonial.

**Ongoing:** Submit AutoTrain 3D to a university showcase and refresh the website with the finished case study.

### 5. Website role
The promotional website is separate from the AutoTrain 3D trainee login portal. It markets D&P itself and uses the following structure:
- Home — brand introduction, value proposition and featured project teaser
- About — mission, vision and values
- Our Work — case studies, led by AutoTrain 3D
- Team — profiles for all four members
- Contact — enquiry form and future social/contact links

### 6. Measurement
Progress will be checked using simple zero-cost indicators: LinkedIn followers and post activity, GitHub profile/repository completion, showcase submission, community posts, website readiness and client testimonial obtained.
